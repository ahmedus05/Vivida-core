# Vivida Network (VIV) - Официальное техническое руководство

Vivida — это децентрализованная криптовалютная экосистема (Layer 1) с открытым исходным кодом, использующая алгоритм консенсуса Proof-of-Work и встроенную систему криптографического клиринга транзакций.

## 📊 Спецификация и Экономика монеты
* **Название:** Vivida
* **Тикер:** VIV
* **Алгоритм:** Proof-of-Work (SHA-256)
* **Базовая награда за блок:** 50 VIV
* **Механизм Халвинга:** Уменьшение награды в 2 раза каждые 210,000 блоков.
* **Защита экономики:** Динамическое уменьшение награды при аномально высокой скорости генерации блоков.

## 🖥️ Установка серверной ноды (Alma Linux / Ubuntu)
```bash
sudo apt update && sudo apt install python3 python3-pip -y
pip3 install -r requirements.txt
nohup python3 vivida_node.py > node.log 2>&1 &
```

## 🌐 API Эндпоинты интеграции для бирж
* `GET /chain/latest` — Возвращает индекс и хэш последнего блока цепочки.
* `GET /balance?address=<PEM_KEY>` — Запрос баланса конкретного адреса.
* `POST /mine` — Валидация и добавление нового смайненного блока.
* `POST /market/sell` — Размещение торгового ордера, подписанного RSA-PSS цифровой подписью.
